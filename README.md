# お助けママ 👩‍👧‍👦

忙しいママのための在庫・買い物・家計管理アプリ

## 起動方法

```bash
npm install
npm run dev
```

## 機能

- ホーム：今週の食費、買い物リスト、作れるメニュー一覧
- 在庫：食品・日用品・子ども用品の在庫管理（残量ステータス）
- 買い物：写真タップ式での買い物リスト追加
- 家計簿：週予算管理、支出記録、カテゴリ集計
- うちレシピ：在庫照合型のレシピ提案（AI不使用）
- 設定：家族構成、味・量の好み設定

## 技術

- React + Vite + TypeScript
- Tailwind CSS
- localStorage（データ保存）
- 外部API・AI・OCR不使用
